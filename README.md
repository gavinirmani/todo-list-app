# 📝 Todo List App

A modern and responsive **Todo List Application** designed to help users organize, manage, and track their daily tasks efficiently.

The project was developed as a practical application of **HTML, CSS, and JavaScript**, focusing on a clean user interface, interactive functionality, and a smooth user experience.

---

## 🚀 Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* ✏️ Edit and manage tasks
* 📋 View pending and completed tasks
* 💾 Store tasks locally in the browser
* 📱 Responsive design
* 🎨 Clean and modern user interface
* ⚡ Fast and lightweight
* 🌙 User-friendly visual design

---

## 🛠️ Technologies Used

* **HTML5** – Application structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and interactivity
* **Local Storage** – Persistent task data

## 🎯 How It Works

The application allows users to create and manage their daily tasks through a simple interactive interface.

### Add a Task

Enter a task in the input field and submit it to add a new item to the task list.

### Complete a Task

Users can mark a task as completed when it has been finished.

### Edit a Task

Existing tasks can be updated when changes are required.

### Delete a Task

Tasks that are no longer required can be removed from the list.

### Data Persistence

Task information can be stored using the browser's **Local Storage**, allowing tasks to remain available after refreshing the page.
